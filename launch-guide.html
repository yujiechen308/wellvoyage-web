4托管：Cloudflare Pages × 2 项目（两站各一个）

免费额度对这两个展示型网站完全够用（无限带宽静态托管）。建两个项目的好处：未来买下 jadeandqi.com 时直接绑上 0 重构。

  1. 登录 Cloudflare → 左侧 Workers & Pages → Create → Pages → Connect to Git。
  2. 按提示授权 GitHub（允许 Cloudflare 读取 wellvoyage-web 仓库）。
  3. 第一个项目：WellVoyage 主站
    • Project name: wellvoyage-web
    • Production branch: main
    • Build command: 留空（纯静态）
    • Build output directory: 填 company-profile（关键！不是空也不是 /）
  4. 第二个项目：Jade & Qi 康养站
    • Project name: wellvoyage-wellness
    • 同样的仓库与分支
    • Build command: 留空
    • Build output directory: 填 wellness-site
  5. 两个都点 Save and Deploy → 各得一个 .pages.dev 地址。
  6. 绑主站域名：在 wellvoyage-web 项目 → Custom domains → 添加 wellvoyagecare.com（Cloudflare 自动配 DNS/SSL）。
  7. 康养站域名暂留：wellvoyage-wellness 项目先留着 .pages.dev 预览地址即可；以后买下 jadeandqi.com 后再加 Custom domains。

为什么不合并到一个项目 + 子路径？

合并到一个项目需要把目录调整为 /index.html + /wellness/index.html，意味着要改 repo 结构、改大量相对路径；不利于未来拆分独立。两个 Projects 维护成本几乎为 0（Cloudflare 自动部署无需人工），却保留最大灵活性。

5收款：PayPal 商业账户 + 支付链接

网站已内置 7 个「Book Now」预订按钮 + 每个按钮的配置槽位；你在 PayPal 后台创建「支付链接」，把链接粘贴到两页配置里即可完成接线。

  1. 打开 paypal.com → 注册 商业账户（Business），用内地营业执照实名 + 绑定对公或法人银行卡收人民币结算。
  2. 进入商家后台 → 顶部 收款 → 支付链接 / Payment Links → 创建链接。
  3. 为每个套餐创建一条链接，金额建议用「可退定金」口径（例如 $500 / ¥），名称填套餐名：
    • Essential Reset（定金）
    • TCM Wellness Retreat（定金）
    • Executive Health Screening（定金）
    • Hearing & Balance Renewal（定金）
    • Longevity & Vitality（定金）
  4. 每条链接创建后复制形如 https://www.paypal.com/ncp/payment/xxxx 的地址，一并发给我。

合规提醒（务必读）

跨境 + 医疗属高风险行业：① 网站与收款用途建议表述为「医疗旅行协调服务 / 行程预订金」，避免在 PayPal 审核或风控时被认定为「医疗诊疗收费」；② 大额定制就医（胸外科/手术类）不建议走在线全款，仍以询盘 + 线下/电汇为主——页面已按此设计；③ 保留每笔交易的咨询记录与书面协议，便于审计。
